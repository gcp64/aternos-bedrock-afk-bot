# 🛡️ Aternos 24/7 Bedrock AFK Bot Guardian

بوت تلقائي خفيف جداً مبني بلغة Node.js للاتصال بسيرفر ماين كرافت بيدروك على أترينوس (Aternos) لإبقائه شغالاً 24 ساعة دون إيقاف تشغيل حتى عندما تكون حاسبتك مغلقة!

---

## 🚀 طريقة التشغيل السحابي المجاني (24/7 Cloud Hosting)

### 🥇 الخيار الأفضل والأسهل: منصة Koyeb (مجاناً مدى الحياة ولا تنام أبداً)
1. افتح موقع: **[Koyeb.com](https://app.koyeb.com)** وسجل دخول بحسابك في GitHub.
2. اضغط **Create App** ثم اختر **GitHub**.
3. اختر مستودعك: **`gcp64/aternos-bedrock-afk-bot`**.
4. اضغط **Deploy**!
5. سيعمل البوت مباشرة في السحابة ويدخل سيرفرك تلقائياً ويبقى شغالاً 24/7 حتى وحاسبتك مطفية تماماً! 🎉

---

### 🥈 الخيار الثاني: منصة Render
1. ادخل إلى **[Render.com](https://render.com)** وسجل دخول بـ GitHub.
2. اضغط **New +** ثم **Web Service**.
3. اختر مستودع `gcp64/aternos-bedrock-afk-bot`.
4. اضغط **Deploy Web Service**.
5. للحفاظ عليه نشطاً دائماً، انسخ الرابط المجاني وأضفه في موقع **[UptimeRobot.com](https://uptimerobot.com)** ليفحصه كل 5 دقائق.

---
